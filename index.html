IntelliGuide

YOLOv8n-Based Real-Time Obstacle Detection System with Multimodal Feedback for Visually Impaired Persons

Artificial Intelligence Computer Vision Assistive Technology Python

IntelliGuide is an academic thesis project focused on developing a real-time obstacle detection system for visually impaired persons. It aims to identify obstacles in front of the user through a camera and provide audio feedback to help communicate potential obstacles during navigation.

System Components

YOLOv8n Used for detecting obstacles in the camera's field of view.
CNN-ViT Intended object classification component to identify detected objects.
Secondary Classifier A pretrained classifier used as fallback when the primary cannot classify an object, depending on final implementation.
Multimodal Feedback Incorporates recorded Tagalog and Bisaya voice feedback.
Four-Second Delay System design includes a delay intended to help prevent overlapping or interrupted speech.

CocoScan

Coconut Disease Detection and Classification System using Computer Vision

Computer Vision Image Classification Deep Learning Python

CocoScan is a project focused on detecting and classifying coconut diseases using computer vision and deep learning techniques. It aims to help identify plant health issues through image analysis, providing a practical tool for agricultural monitoring.

System Components

Image Capture Supports capturing a leaf with the camera or choosing an existing image to upload.
Disease Classifier Classifies leaf scans and displays a result with a confidence score.
Results Display Provides scan details, result information, recommendations, and scan history.

Foodie Finder

A local food and restaurant discovery platform for Naval Proper

Web Application Restaurant Discovery Responsive UI Naval Proper

Foodie Finder is a web project for helping people discover restaurants, meals, snacks, and drinks in Naval Proper. Its screenshots show the welcome page, account registration and login screens, and an About page outlining its discovery features.

Project Features
